Checking out a tree that contains a directory named `.GIT` should be treated the same as `.git`, and so should a name with a zero-width joiner slipped between the `g` and the `i` (`.g` + U+200D + `it`). The matcher currently panics on every path component, so checkout dies before it can accept or reject anything. A real `.gitmodules` directory must still be allowed. I only noticed because a crafted tree with the joiner variant checked out on a Mac volume and Git itself refused it.
