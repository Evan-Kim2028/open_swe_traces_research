Section lookup in git config is case-blind for ASCII (`[Core]` vs `[core]`) but two names that Unicode considers the same letter are missing each other. A section named with a long s (U+017F) should hit the same slot as `s`, and the kelvin sign (U+212A) should hit `k`. Lowercasing the name with the obvious API is not enough; those two still miss. Decoding a `.gitmodules` file that uses a funny S in the section name currently panics instead of finding the section.
