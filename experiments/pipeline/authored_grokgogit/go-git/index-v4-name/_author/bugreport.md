Writing a v2 index of a few files (`bar`, `foo`, and a twenty-space name) and reading it back used to round-trip, including the sort order and the 8-byte alignment Git expects between entries. A v4 index of those same names plus `baz/bar` and `baz/bar/bar` also round-tripped, with the later names sharing a prefix so the file stayed small. Both writes now panic in the name/padding step, so `git status` against an index we just wrote fails.
