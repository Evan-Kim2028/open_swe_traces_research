The git:// handshake line is coming out wrong. For command `command`, path `pathname`, host `host`, and extra parameters `param1` and `param2`, the pkt-line payload has to be those fields separated by NULs, with an extra NUL before the extra parameters, and it has to end with a NUL. An empty command must be rejected. Encoding currently panics, so a `git://` clone never sends the request.
